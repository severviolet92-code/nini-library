# مكتبة نيني

دليل تشغيل شخصي لأدوات الذكاء الاصطناعي بالعربي: **69 أداة مختارة** مرتّبة في خطة من **7 مراحل** — سكيلات، خوادم MCP، وأدوات سطر أوامر — مع أمر التركيب جاهزاً للنسخ بجانب كل واحدة.

**الموقع:** https://severviolet92-code.github.io/nini-library/

## ماذا بداخلها

| القسم | المحتوى |
|---|---|
| الخطة الكاملة | 7 مراحل، كل أداة في مكانها وترتيبها |
| العدّة | 69 أداة (31 سكيل · 16 خادم MCP · 12 أداة · 5 CLI · 5 حزم) |
| يوم التركيب | الأدوات الست الأساسية للبداية |
| الوصفات | 4 مسارات جاهزة: هوية بصرية، موقع، فيديو إعلاني، ماركة ملابس |
| القواعد | كيف تخلط بين السكيلات وخوادم MCP بدون فوضى |

كل الأدوات مجانية أو مشمولة باشتراك Claude.

## المصدر

الأوامر منقولة حرفياً من بطاقات الوصفات في [مكتبة سلمان](https://maktaba-alpha.vercel.app/) كما كانت في 10 أغسطس 2026.
