الخطة الكاملة — ماذا تستعملين، ومتى، وبأي ترتيب

كل المراحل السبع أمامك دفعة واحدة. داخل كل مرحلة الأدوات مرقّمة بترتيب التنفيذ، وبجانب كل اسم نوعه: سكيل MCP CLI أداة حزمة. التفاصيل وأوامر التركيب في تبويب «العدّة».

يوم التركيب: نصف ساعة، مرة واحدة

ستة فقط. كل أمر ينسخ ويلصق في الترمنال وأنتِ داخل مجلد أي مشروع، ثم أغلقي Claude Code وافتحيه.

القاعدة

لا تركّبي كل شيء. الخطأ الأول عند كل مبتدئ هو تركيب 30 سكيل في يوم واحد، فيتشتت الوكيل وتتشتتين معه.

الستة هنا أساسك الدائم. أي أداة أخرى في «العدّة» تركّبينها لحظة احتياجك لها فقط — والخطة تقول لك متى.

بعد هذه الستة، ارجعي لتبويب «الخطة» وركّبي من كل مرحلة ما تحتاجينه عند وصولك إليها.

    أربع وصفات تنسخينها كما هي

    كل خطوة فيها نص جاهز تلصقينه في Claude Code. نفّذي الوصفة حرفياً أول مرة، ثم عدّليها على ذوقك.

    كيف تخلطين بينها

    ست قواعد تمنع أغلب الفوضى التي تحصل عند الخلط بين عدة سكيلات وخوادم.

    01 سكيل واحد لكل رسالة

    لا تكتبي «استخدم brandkit و impeccable و copywriting» في طلب واحد. اطلبي واحداً، خذي مخرجه، ثم اطلبي الذي بعده وأعطيه المخرج السابق. هذه القاعدة وحدها تحل أغلب المشاكل.

    02 مجلد مستقل لكل مشروع

    السكيلات تقرأ وتكتب في المجلد الذي أنتِ فيه. مشروعان في مجلد واحد يعني هويتين مختلطتين وملفات ضائعة.

    03 السكيل يفكّر، والـ MCP يتصل

    الفرق باختصار: السكيل يعلّم Claude طريقة عمل (كيف يصمم، كيف يكتب). خادم MCP يوصله بخدمة خارجية (Figma، Stripe، متصفح، قاعدة بيانات). تحتاجين الاثنين لكن في لحظات مختلفة.

    04 الصورة قبل الكود، والنص قبل الشكل

    سكيل image-to-code يولّد صورة تصميم لكل قسم أولاً فتعتمدينها بعينك. واكتبي نصوص الصفحة قبل تصميمها — التصميم المبني على نص حقيقي يطلع صحيحاً من أول مرة.

    05 أعيدي التشغيل بعد كل تركيب

    أي npx skills add أو claude mcp add لا يظهر أثره حتى تغلقي Claude Code وتفتحيه. تأكدي بأمر /mcp أن الخادم ظاهر.

    06 اطلبي التوقف عند كل مرحلة

    أضيفي في نهاية كل طلب: «اعرض علي النتيجة قبل أن تكمل». يمنعك هذا من اكتشاف خطأ بعد أن يبني الوكيل عشر خطوات فوقه.

    ما لا تحتاجينه الآن — ولماذا

    أدوات ممتازة في المكتبة لكنها ليست لك في هذه المرحلة. مذكورة حتى لا تضيّعي أسبوعاً في استكشافها.

    Higgsfield · Runway · Pika · HeyGen · Descript · Lovart أدوات صور وفيديو ممتازة لكنها كلها برصيد مدفوع فوق اشتراكك. الوصفة الثالثة تعطيك فيديو إعلانياً بدون أي منها.
    Codex CLI · OpenCode · GLM · MiniMax · Claude Code Router بدائل ونماذج أخرى. عندك Claude، وأضفت لك Gemini CLI مجاناً كوكيل ثانٍ — هذا يكفي تماماً.
    Graphify · Caveman · Graft · LoopX أدوات توفير التوكنز، وفائدتها تظهر في مشاريع برمجية ضخمة بآلاف الملفات. مشاريعك أصغر من أن تحتاجها.
    AWS · Azure · Prisma · Neon · Docker · Sentry بنية تحتية لفرق هندسية. مواقعك تُنشر على Vercel بأمر واحد، و Supabase يكفي لأي قاعدة بيانات تحتاجينها.
    Cybersecurity · Scientific Agent Skills · TradingAgents · OpenBB · Career-Ops مجالات كاملة بعيدة عنك: أمن، أبحاث علمية، تداول، توظيف. ممتازة — لكن لشخص آخر.
    n8n · Zapier · Lindy · Blender MCP · Okara أتمتة وثلاثي أبعاد وحملات مؤثرين. ارجعي لها بعد أن يكون عندك عملاء متكررون ومهام تتكرر أسبوعياً — الأتمتة تُبنى فوق روتين موجود، لا قبله.
